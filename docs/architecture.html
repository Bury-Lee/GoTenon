GoTenon 插件内核 · 架构图

宿主接入 · 依赖收敛 · 插件生命周期 · 上下文与副作用 · 消息管道

依赖收敛（graph.go / converge.go）

  • • Register 查重 + DFS 环检测，失败回滚
  • • Enable 拉取依赖闭包，波次内并行装载
  • • 依赖未就绪保持 PENDING，Missing 标注缺口
  • • 引用归零自动卸载，依赖者先走

上下文与副作用（context.go / effect.go）

  • • parent 链继承，子永不修改父
  • • Isolate 私有槽 / IsolateLabel 共享槽
  • • Intercept 配置层 root-first 合并
  • • 一切注册皆 Disposer，卸载逆序回收

生命周期与扩展（lifecycle.go / loader.go）

  • • Apply → Start → Run，失败回滚半成品
  • • 七态状态机 + Enable 意图位（Kept 保留装载）
  • • 装载超时放弃等待并清理上下文
  • • End → 逆序回收 → cleanContext
  • • Loader 五钩子 + Timeout / Concurrency
